# 🎯 QuizSphere - Web Technologies Quiz

QuizSphere is an interactive web-based quiz application focused on Web Technologies. It provides a timed quiz experience along with detailed result analysis and downloadable reports.

---

## 🚀 Features

* 🧠 10 Multiple Choice Questions
* ⏱️ 15 Seconds Timer for Each Question
* 📊 Quiz Summary After Completion
* ✅❌ Review of Correct and Wrong Answers
* 📄 Download Results as PDF
* 🔁 Try Again Option
* 🌙☀️ Light & Dark Mode Toggle
* 🎥 Demo Video Included

## 📌 How It Works

1. Start the quiz
2. Answer each question within 15 seconds
3. View the summary after completing the quiz
4. Review correct and incorrect answers
5. Download your result as a PDF (optional)
6. Click "Try Again" to retake the quiz
